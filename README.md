# ระบบยืนยันรายชื่อและรายงานตัวนักกีฬา

เว็บให้โรงเรียนยืนยันหรือแก้ไขรายชื่อนักกีฬาก่อนวันแข่ง **โดยไม่ต้องล็อกอิน** และให้เจ้าหน้าที่ดูสถานะ พิมพ์ใบรายงานตัว และส่งออก Excel ผ่านหลังบ้านที่มีบัญชีผู้ใช้ ระบบเดียวรองรับหลายการแข่งขัน

ใช้ครั้งแรกกับ **กีฬาเปตอง การแข่งขันกีฬาสาธิตสามัคคี ครั้งที่ 49 “คำมอกหลวงเกมส์”**

## ความสามารถ

**ฝั่งโรงเรียน** (`/c/<รหัสลิงก์>`)
- เลือกโรงเรียน → ระดับชั้น → รายการ → ยืนยัน แก้ชื่อ หรือถอนตัว พร้อมกรอกชื่อผู้ยืนยันและเบอร์โทร
- ปิดรับยืนยันอัตโนมัติตามเวลาที่ตั้งไว้ของแต่ละรายการ
- จำกัดจำนวนรายการต่อคน (ค่าเริ่มต้น 3) มีตัวนับให้เห็นระหว่างกรอก

**หลังบ้านเจ้าหน้าที่** (`/admin`)
- บัญชีผู้ใช้ 2 บทบาท: **ผู้ดูแลระบบ** (จัดการการแข่งขันและบัญชี) และ **เจ้าหน้าที่** (ดู พิมพ์ ส่งออก แก้แทนโรงเรียน)
- สร้างการแข่งขันใหม่ด้วยการอัปโหลด Excel รายชื่อ พร้อมโลโก้
- ตั้งวันแข่ง เวลาเริ่ม และเวลาปิดยืนยัน ทีละประเภทหรือทีละรายการ มีปุ่มตั้ง "18.00 น. วันก่อนแข่ง"
- ภาพรวมการยืนยันรายวันและรายโรงเรียน
- พิมพ์ใบรายงานตัว A4 (เฉพาะชื่อที่ยืนยันแล้ว) และส่งออก Excel
- ประวัติการแก้ไขทุกครั้ง: ก่อน → หลัง, ใครแก้, เบอร์โทร, บัญชีเจ้าหน้าที่

## ติดตั้ง

ต้องมี Python 3.10 ขึ้นไป

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 app.py
```

เปิด <http://localhost:8000/admin> ครั้งแรกระบบจะให้สร้างบัญชีผู้ดูแลระบบ จากนั้นกด "สร้างการแข่งขันใหม่" แล้วอัปโหลดไฟล์ Excel

- เปลี่ยนพอร์ต: `PORT=8080 python3 app.py`
- ย้ายที่เก็บข้อมูล: `CHECKIN_DATA=/path/to/data python3 app.py` (ค่าเริ่มต้นคือโฟลเดอร์ `instance/`)

## รูปแบบไฟล์ Excel

แผ่นงานแรก ต้องมีแถวหัวตารางที่มีคอลัมน์ต่อไปนี้ (ชื่อคอลัมน์ไม่ต้องตรงทุกตัวอักษร ระบบหาจากคำสำคัญ)

| คอลัมน์ | จำเป็น | ตัวอย่าง |
|---|---|---|
| รายการแข่งขัน/ประเภทกีฬา | ✓ | เปตอง : มัธยมศึกษาตอนต้น คู่ ชาย |
| โรงเรียน | ✓ | โรงเรียนสาธิต... |
| ชื่อ | ✓ | กล้า |
| นามสกุล | ✓ | ตัวอย่าง |
| คำนำหน้า | | ด.ช. |
| ระดับชั้น | | มัธยมศึกษาตอนต้น |
| คู่ที่/ทีมที่/มือวาง | | 1, 2 หรือ 999 (= ไม่ระบุ / ประเภทบุคคล) |

ประเภทของรายการ (เดี่ยว, Shooting, คู่, คู่ผสม, ทีม) ระบบแยกจากชื่อรายการเอง

ไฟล์ตัวอย่าง (ข้อมูลสมมติ): [`examples/sample_athletes.xlsx`](examples/sample_athletes.xlsx) ใช้ลองระบบได้ทันที

## คำสั่งจัดการ

```bash
python3 manage.py create-user somchai --role staff --name "ครูสมชาย"
python3 manage.py reset-password admin      # ลืมรหัสผ่าน
python3 manage.py list-users
```

## โครงสร้าง

```
app.py              เปิดเซิร์ฟเวอร์ (waitress)
manage.py           คำสั่งจัดการบัญชี
checkin/
  __init__.py       สร้างแอป, ตั้งค่าความปลอดภัย
  db.py             โครงสร้างฐานข้อมูล SQLite
  logic.py          กติกาการยืนยัน (ทดสอบแยกได้)
  importer.py       อ่าน Excel
  auth.py           บัญชีผู้ใช้และสิทธิ์
  public.py         API หน้าโรงเรียน
  admin.py          API หลังบ้าน
static/             หน้าเว็บ (HTML/CSS/JS ไม่ต้อง build)
tests/              python3 -m pytest -q (GitHub Actions รันให้อัตโนมัติทุกครั้งที่ push)
examples/           ไฟล์ Excel ตัวอย่าง (ข้อมูลสมมติ)
instance/           ข้อมูลจริง: ฐานข้อมูล โลโก้ กุญแจ session (ไม่ขึ้น git)
```

## ความปลอดภัยและข้อมูลส่วนบุคคล

- รหัสผ่านเก็บแบบ hash, session หมดอายุใน 12 ชั่วโมง, จำกัดการลองรหัสผิด, กัน CSRF ด้วย header
- **รายชื่อนักกีฬาเป็นข้อมูลส่วนบุคคลของนักเรียน** `.gitignore` กันไฟล์ `.xlsx`, ฐานข้อมูล และโฟลเดอร์ `instance/` ไม่ให้ขึ้น GitHub แล้ว ตรวจด้วย `git status` ก่อน push ทุกครั้ง
- ถ้าเปิดให้ใช้ผ่านอินเทอร์เน็ต ให้ใช้ HTTPS (เช่นผ่าน reverse proxy หรือบริการ hosting) และตั้ง `COOKIE_SECURE=1`
- สำรอง `instance/checkin.db` เป็นระยะช่วงเปิดรับยืนยัน
